# Advent of Code Solutions

My solutions to [Advent of Code](https://adventofcode.com/), written in Go.

## Structure

Solutions are organized by year and day:

    2024/
    ├── day01/
    │   ├── input.txt
    │   └── ...
    ├── day02/
    │   ├── input.txt
    │   └── ...
    └── ...

## Running a Day

Make sure you have [Go](https://go.dev/) installed.

Each day's solution expects the Advent of Code input to be provided in an `input.txt` file in the same directory as the solution.

For example, to run Day 1 of 2024:

    go run ./2024/day01

The input should be located at:

    2024/day01/input.txt

Replace the year and day as needed:

    go run ./2025/day05

with the input located at:

    2025/day05/input.txt

### Input

Input files are not included in this repository. Download your personal puzzle input from [Advent of Code](https://adventofcode.com/) and save it as `input.txt` in the corresponding day directory.
